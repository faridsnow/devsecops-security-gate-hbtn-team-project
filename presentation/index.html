Niyə Bu Layihəyə Ehtiyac Var?

  • 2024 — Mercedes-Benz Leak: Developer GitHub-a şirkətin daxili API key-lərini push etdi. Bütün source code, dizayn sxemləri və cloud infrastructure sızdı.
  • Hücumların 80%-i third-party dependency-lərdəki CVE-lərdən (bilinen vulnerability) qaynaqlanır.

  • Manual code review insani xətaya meyillidir — developer yorğunluğu, deadline pressure, gözdən qaçırma.

Layihə Haqqında

Necə İşləyir?

DevSecOps Automated Security Gate — developer kod push edən anda avtomatik işə düşən zero-cost security pipeline-dır. Sistem kodu üç müstəqil engine ilə scan edir və CVSS v3.1 scoring-ə əsasən gate keçid qərarı verir.

💡 5 müstəqil Python engine sıfırdan yazılıb. Heç bir hazır kommersiya aləti istifadə olunmayıb (Semgrep, Trivy, SonarQube yoxdur). Tam custom, tam portable.
🏛️ OWASP Top 10, NIST SP 800-218 və CIS Benchmarks standartlarına uyğundur.

Features

Əsas Xüsusiyyətlər

🔑

Secret Scanning

8 regex rule ilə AWS Key, OpenAI API Key, GitHub Token, SSH Private Key, hardcoded password aşkarlayır. Comment-lərin içini belə scan edir.

Critical
🛡️

SAST Engine

SQL Injection (f-string & concat), eval/exec RCE, os.system Command Injection, Pickle Deserialization, Weak Hash (MD5/SHA1), 0.0.0.0 binding.

6 Rule
📦

SCA Scanner

requirements.txt və package.json parse edir, hər package-i Google OSV.dev API ilə global CVE database-ə qarşı yoxlayır. CVE-based deduplication.

New
📊

Live Dashboard

Real-time web dashboard: CVSS risk score, severity chart, scan history, finding details. Render.com-da deploy, auto-refresh hər 30 saniyə.

Live
🚨

Telegram Alerts

Hər scan nəticəsini Telegram channel-ə göndərir. BLOCKED olduqda dərhal bildiriş — komanda real-time xəbərdar olur.

Instant
🔧

Auto-Remediation

Hər vulnerability üçün konkret fix recommendation generasiya edir. Remediation engine diff-format patch hazırlayır.

Gələcək Planlar

Roadmap & Vision

Phase 1 — Q4 2026

🌐 DAST Integration

Dynamic Application Security Testing — deploy olunmuş app-a real HTTP request-lərlə hücum simulyasiyası. HTTP Security Headers, CORS misconfiguration, open redirect yoxlaması.

Phase 2 — Q1 2027

🤖 AI-Powered Analysis

Gemini Flash API ilə hybrid scan: regex + AI. False positive azaltma, business logic vulnerability aşkarlama, smart auto-fix suggestion generasiyası.

Phase 3 — Q2 2027

🌍 Multi-Language Support

JavaScript/TypeScript, Go, Java, C# dəstəyi. Hər dil üçün language-specific SAST rule-lar. Polyglot monorepo scan imkanı.

Phase 4 — Q3 2027

☁️ SaaS Platform

Multi-tenant cloud platform: team dashboard, organization-wide policy management, compliance reporting (SOC 2, ISO 27001), GitHub/GitLab App Marketplace integration.
